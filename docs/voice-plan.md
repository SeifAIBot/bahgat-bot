# Voice plan — Bahgat's voice
- v1: Edge TTS, ar-EG male voice, free. Good enough to test triggers + voice rules.
- v2: XTTS v2 zero-shot from ~6 sec clean clip (fast test, Arabic supported).
- v3: RVC trained on 10-20 min clean audio, or GPT-SoVITS from 1-10 min clean audio.
  RVC needs 10 min clean, no background noise. GPT-SoVITS can start from 1 min.
- Exact 100% match is NOT promised, especially shouting / laughing.
- Bot must be labelled parody in its bio, not the real Bahgat Saber.
- Dataset: see docs/training-videos.md section A. Verify cleanliness by listening before training.
