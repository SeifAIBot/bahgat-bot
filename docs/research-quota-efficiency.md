# Research: efficiency — how far can free stack stretch for 15 users / 100 replies each (2026-11-25)

Independent web research (10 searches) + fresh read of v0.5 code (brain/router.py, brain/prompt.py, brain/memory.py, config/providers.yaml, tg/handlers.py). No files edited.

## Bot's real token profile (v0.5 code)
System prompt SYSTEM_BASE 634 chars + hard-rules ~200 + persona ~150 + member/mood ~150 + 3 few-shot pairs ~550 = ~1,700 chars ~650 tokens (o200k-family; cl100k ~1.5x higher). History 8 msgs x ~120 chars ~960 chars ~400 tokens. Memory block notes+grudge capped 200+200 chars ~400 chars ~150 tokens. User message ~50 chars ~25 tokens. Input plain chat ~1,200. Search excerpt (+1,500 chars) ~+800 -> ~2,000 input. Output visible 150-300 + reasoning (low) ~100-250 ~350. Total per plain reply ~1,550 tokens; per search reply ~2,400. Traffic mix 70% chat / 20% search / 10% unknown-retry double-call -> weighted ~1,700 tokens per served reply. Groq charges prompt_tokens + max_completion_tokens against 8,000 TPM window BEFORE generating, so chat call reserves ~1,200+1,500=2,700 TPM (~3 calls/min/model). 1,000 RPD cap per Groq model never binds — TPD binds first (200,000 / 1,700 ~ 118 calls/model/day).

## Capacity math — current v0.5 vs target
Current v0.5 as configured: ~100 replies/day. Router self-cap groq_daily_token_cap: 150,000 counted COMBINED across 120b+20b (usage keyed by provider name "groq"), plus Gemini capped 15 req/day: 150,000/1,700 ~ 88 + 15 ~ ~100/day. 30/user/day + 150/group/day quota NOT binding — provider caps are, and config wastes most of real pool: Groq limits PER MODEL (200k TPD each), so 120b+20b+qwen/qwen3.8-27b = 600k tokens/day real pool, not 150k.
Target 1,500 replies/day ~ 1,500 x 1,700 ~ 2.55M tokens/day. Current hosted pool (Groq 600k + Gemini ~30k) ~630k — roughly 4x short. No single tweak closes gap; needs provider pooling + efficiency stacked.

## Ranked efficiency levers (replies/day gain)
Baseline: per-model Groq caps + qwen = 600k pool; per-call 1,700 tokens -> ~350/day hosted (before Cerebras).
1. Add Cerebras as provider: new adapter (OpenAI-compatible base URL swap), gpt-oss-120b, own 1M/day cap in provider_usage, route after Groq. +590/day (1M/1,700) — biggest single lever. Low effort (one key, one adapter). Verify live limits + model ID first; free tier churns.
2. Split Groq caps per model + add qwen3.8-27b: track provider_usage per (provider, model) not per provider; cap 180k each; qwen as 3rd Groq tier. +260/day (600k vs 150k pool -> 350 vs 88/day). Low. qwen preview — may be discontinued; keep last.
3. Groq prompt caching — exploit it: move dynamic [MEMBER]/[MOOD] blocks OUT of middle of system prompt (v0.5 interleaves them — breaks prefix caching) so static ~650-token prefix identical every call; read usage.prompt_tokens_details.cached_tokens to track real burn. ~+60-70% on Groq-served replies (effective ~700 tok/call instead of 1,700 on hits -> 600k/700 ~ 855/day vs 350). Low. Caveat: hits not guaranteed, 2h TTL, cached tokens still subtracted after processing in parallel bursts.
4. Prompt compression: history 8->4 msgs (-~200 tok), examples 3->2 pairs (-~200), search excerpt 1,500->800 chars (-~270), trim SYSTEM_BASE 634->~450 chars (-~70). Literature manual compression 20-40%, context management 30-60%. Per-call 1,700 -> ~1,050 (-38%) -> ~+60% capacity on any fixed pool. Low-medium. A/B-test persona quality; don't over-trim hard rules.
5. Gemini Flash-Lite as tier (500 RPD): add gemini-3.1-flash-lite / gemini-3.5-flash-lite as provider entry, route simple chat there when Groq/Cerebras hot. +500/day (request-capped; tokens not binding). Low. Verify model ID + live RPD in AI Studio; quality-check few banter replies first.
6. Response caching (exact + semantic): exact-match cache first (SQLite TTL 1h greetings only); then semantic cache with LOCAL sentence-transformers embeddings + FAISS (no API cost), similarity >=0.90, keyed normalised text + mood bucket + intent, NEVER for search/insults/grudge replies. Literature: exact-match only 4-18% hit rate production; semantic 60-70% hit rate, 67-73% cost cut (VentureBeat, GPTCache paper 61.6-68.8%) — but those are FAQ/support traffic; free-form group banter conservative 20-30% hit rate. +25-40% effective capacity. Medium. Main risk stale/wrong-context roast — keep thresholds high, exclude mood-dependent replies.
7. Kill unknown-retry double call: search BEFORE first call for factual questions (intent already detects most); retry only when search returned genuinely new info; log retry rate. ~+10% (retry fires ~10% chat calls today, each costing full second call). Low.
8. Output cap 1,500 -> 600 for chat: visible replies 1-3 sentences (<400 chars ~200 tokens); reasoning-low adds ~150-250. 600 generous headroom. Also cuts TPM reservation (1,200+600 vs 1,200+1,500) -> ~50% more calls/min headroom. ~+10-15% TPD + burst headroom. Low.
9. Mistral free tier: add as overflow tier simple chat only (2 RPM). +1,000-2,000/day potential. Medium; verify console limits + Arabic quality first — tier may have changed.
10. Self-hosted 3B on Oracle (tier-0 greetings): Ollama + Qwen2.5-3B/Llama-3.2-3B, greetings/small-talk only, Groq fallback on timeout. +300-450/day (absorbs ~20-30% traffic). High (VPS, security, capacity lottery). Weakest quality — gate tightly.
11. Cloudflare Workers AI: last-resort tier. +100-200/day. Low.

### Stacked scenario (conservative)
v0.5 today (Groq 150k combined + Gemini 15): 1,700 tok/reply -> ~100/day. + per-model Groq caps + qwen (600k): 1,700 -> ~350/day. + Cerebras 1M: 1,700 -> ~940/day. + prompt compression (->1,050 tok/reply): 1,050 -> ~1,520/day. + Groq prefix caching (Groq ~700/reply): mixed -> ~1,800/day. + Gemini Flash-Lite 500 + Flash 20: -> ~2,320/day. + response caching (+25% effective): -> ~2,900/day. + Mistral + Cloudflare (uncertain): -> ~4,000/day.
Bottom line: 1,500/day reachable free, but only with Cerebras + Flash-Lite + compression + caching stacked — apply ~50% haircut for free-tier churn (models deprecated, limits move without notice) -> ~1,450/day pessimistic, ~2,900/day expected. Without Cerebras expected drops ~1,900/day (haircut ~950 — short). Cerebras is load-bearing addition; Mistral/local-3B safety margin not plan.
Per-minute sanity at 1,500/day over ~16 active hours: ~94/hour ~ 1.6/min average — no RPM binds except Mistral (2 RPM, route overflow only) and Groq TPM in bursts (mitigated 4+ providers + caching).

## Recommended quota scheme (15 friends, 1-2 groups)
Do NOT promise 100/user/day as hard guarantee — 15x100=1,500/day is exactly whole (optimised) pool, so first day all 15 go full-tilt pool is gone. In practice 15 friends won't each send 100 bot-triggered messages/day (realistic 20-60/user/day), so design for fairness not worst case:
- Per-user: 100 replies/day hard cap (Seif's number — headline promise), PLUS 20/hour burst cap (stops one spammer eating pool in 20 min; 20/hour still generous for real conversation).
- Per-group: 1,500 replies/day shared pool — real budget; per-user caps are fairness, group pool is ceiling.
- Cached replies (exact/semantic hits) do NOT count against any quota — cost zero tokens, stretches pool for most common traffic.
- Search / YouTube / voice DO count (cost more; YouTube download costs download+upload not just tokens).
- Owner exempt (or 200/day); when group pool drops below 20%, degrade gracefully: cheap tiers only (20b/Cerebras/Mistral), cached replies keep working, one in-character "battery low" notice per hour — never silent dead bot.
- Measure in replies per user, tokens per group (providers bill tokens; friends understand replies). Log both in /stats.

## Recommended routing order (after levers)
Tier 0: response cache (exact -> semantic). Tier 1 simple chat: Groq 20b (prefix-cached) -> Cerebras gpt-oss-120b -> Mistral Small -> local 3B (if built). Tier 2 hard/search: Groq 120b -> Cerebras 120b -> Gemini Flash-Lite -> Gemma 3 27B -> Gemini Flash (20/day, search synthesis only). Reserve nothing for Gemini Flash beyond that.

## Caveats — verify before building on any number
Free tiers churn constantly: GitHub Models retired 2026-07-30; Groq dropped Llama; Cerebras deprecated models 2026-02-16. Read each provider's live limits page in its console (Groq Settings -> Limits; AI Studio rate-limit table; Cerebras dashboard) before trusting any figure here including mine. Google no longer publishes Gemini per-model table at all. Gemini Flash-Lite / Gemma numbers per-project "not guaranteed" — Seif should read own AI Studio page. Cerebras free context cap 8,192 tokens — prompts here ~1-3k fine, keep search excerpt capped. Prompt-caching gains assume static prefix byte-identical across calls — current v0.5 prompt violates this (dynamic blocks in middle); fix first or caching lever worth ~0.
